# postfixadmin-reconcile-orphans

This project is hosted on Codeberg:

### **[https://codeberg.org/DuncanRobertson/postfixadmin-reconcile-orphans](https://codeberg.org/DuncanRobertson/postfixadmin-reconcile-orphans)**

A read-only reporting tool that reconciles `/var/vmail` against a
[PostfixAdmin](https://postfixadmin.github.io/postfixadmin/) database, listing
orphaned and inactive domains and mailboxes with their disk usage.
Python 3, using the `mysql` CLI client. Nothing is modified or deleted.
